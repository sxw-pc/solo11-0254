# 集群事件订阅与告警抑制仲裁庭

本项目是离线云原生业务控制面模拟。使用 Python 标准库和 SQLite；数据、身份与时间均为合成 fixture，不操作真实集群。

## 三个业务子系统

### 事件语义庭

同代事件合并为事故线索但不同资源代际不得混案。持久化：event_sources,raw_events,correlations 分别保存身份、代际、状态与相互引用的决定凭据。

入口：`python -m eventcourt incident --db state.sqlite --fixture fixtures/incident_normal.json`。

### 订阅责任庭

按事件对象当前归属与值班窗口确定唯一主接收方。持久化：subscriptions,oncall_windows,ownership_claims 分别保存身份、代际、状态与相互引用的决定凭据。

入口：`python -m eventcourt duty --db state.sqlite --fixture fixtures/duty_normal.json`。

### 抑制与送达庭

有范围和截止的维护授权才暂缓告警，窗口结束须补发未确认事故。持久化：suppression_grants,deliveries,ack_receipts 分别保存身份、代际、状态与相互引用的决定凭据。

入口：`python -m eventcourt delivery --db state.sqlite --fixture fixtures/delivery_normal.json`。

## 首版业务能力

1. **来源事件固化**：来源事件固化 的独立裁定：保存来源 UID、对象代际和单调序号以区分重试。失败边界：来源事件固化 的异常输入或迟到事实：同 ID 不同内容拒绝
2. **事故相关性裁定**：事故相关性裁定 的独立裁定：相同服务和故障链的事件可合案但代际更替必须分案。失败边界：事故相关性裁定 的异常输入或迟到事实：发布失败与硬件故障不可混为一案
3. **事故拆分追索**：事故拆分追索 的独立裁定：错误合案可依据原始事件重算并保留两份事故证据。失败边界：事故拆分追索 的异常输入或迟到事实：已通知事故不得静默删除
4. **订阅范围生效**：订阅范围生效 的独立裁定：服务标签与团队合同决定事件通知范围。失败边界：订阅范围生效 的异常输入或迟到事实：标签变更不能追溯改写已送达记录
5. **值班责任交接**：值班责任交接 的独立裁定：交接须双方回执与明确生效时刻。失败边界：值班责任交接 的异常输入或迟到事实：单方声明不能使旧班责任消失
6. **维护抑制授权**：维护抑制授权 的独立裁定：抑制须匹配对象、故障类别和有限时间窗。失败边界：维护抑制授权 的异常输入或迟到事实：宽泛授权不可抑制高危故障
7. **告警投递选择**：告警投递选择 的独立裁定：按事故代际、责任人和抑制状态决定投递或暂缓。失败边界：告警投递选择 的异常输入或迟到事实：重试不得多次通知不同主接收方
8. **窗口结束补发**：窗口结束补发 的独立裁定：过期抑制的未确认事故恢复投递并关联原证据。失败边界：窗口结束补发 的异常输入或迟到事实：迟到确认不得让补发事故凭空消失

## 本地运行与验证

在仓库根目录运行：

```sh
python -m eventcourt demo --db demo.sqlite
python -m eventcourt replay --db demo.sqlite
python -m unittest discover -s tests -v
```

每个子系统提供一份独立正常 fixture 与一份实质失败 fixture；`fixtures/path.json` 串联跨子系统场景。每条命令保留原始输入、决定与不可变事件，`replay` 在空数据库重建状态并逐表核验。

## 业务边界

- **事件语义庭 → 订阅责任庭**：服务 svc-a 的发布故障事件被关联为事故 inc-1，交接生效后的 team-b 成为主接收方；旧 team-a 的订阅回执仍保留历史责任。失败分支：迟到旧资源代际事件不得并入 inc-1 并重置接收人
- **订阅责任庭 → 抑制与送达庭**：team-b 对 svc-a 类别 deploy 在 10–20 的维护授权使 inc-1 暂缓投递；同一窗口的硬件故障 inc-2 仍立即送达。失败分支：窗口 20 之后才补录授权不得倒消已送达的故障通知
- **事件语义庭 → 抑制与送达庭**：inc-1 在维护窗口结束后仍未确认，投递庭向当前值班 team-c 补发并保留 team-b 原责任记录。失败分支：旧班迟到确认不能抹去 team-c 已形成的补发决定

该仓仅实现本地业务状态与回执协议；不连接真实 Kubernetes、设备插件、时间服务或告警平台。
